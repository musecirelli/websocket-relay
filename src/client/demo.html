Comms Shim — Relay Tool demo

Start localhostServer first (make run in the repo root). This page loads snippet.js exactly like a console paste does: the snippet loads MQTT.js, connects to localhostServer's MQTT broker (ws://127.0.0.1:8083), loads the Relay Tool from the server, and the tool window appears in the top-right corner. Use its Echo and Chat panels — or the buttons below, which call the same connection.
